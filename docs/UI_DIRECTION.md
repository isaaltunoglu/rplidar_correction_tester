## Direction contract

THESIS: Let someone with no sensor or file-format knowledge choose a direction, understand a measurement, run a guided test and watch a recording. Instructions and useful next actions precede technical data.

OWN-WORLD: Retain ink-blue navigation, warm paper work areas, dark plots and terracotta angular selections. Locally served Manrope now uses larger body text and controls. Labelled disclosures retain all technical capabilities.

STORY: The visitor chooses a real USB sensor or an explicitly computer-generated example, picks front/rear/all directions, then reads a distance. Tests explain preparation in three steps and accept centimetres. Human-readable results and reports come first. Recordings can be watched on the same page without downloading, with source, duration, playback and file-purpose explanations.

FIRST VIEWPORT: A horizontal navigation bar frames a source notice, plain heading and source choice. Desktop has simple direction/result controls beside the large plot; mobile shows direction choices, the plot, then its result. Technical telemetry, filters and raw exports start closed. Test and recording pages expose clear sequential instructions, not a technical dashboard. Existing finite motion settles before capture.
