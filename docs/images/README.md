# README ekran görüntüleri

Bu PNG dosyaları, uygulamanın gerçek Chrome tarayıcısında çalışan sensörsüz örnek modundan alınmıştır. Üretilmiş arayüz taslakları veya fiziksel sensör ölçüm kanıtları değildir. Görseller yeniden boyutlandırılmadan ve içerikleri değiştirilmeden kopyalanmıştır.

| Dosya                    | Kaynak tarayıcı çıktısı                           |
| ------------------------ | ------------------------------------------------- |
| `canli-goruntu.png`      | `artifacts/browser/desktop-live.png`              |
| `mesafe-ve-uyarilar.png` | `artifacts/browser/desktop-distance-settings.png` |
| `adim-adim-test.png`     | `artifacts/browser/desktop-experiment.png`        |
| `kayit-ve-izleme.png`    | `artifacts/browser/desktop-replay-player.png`     |

Görüntülerin kaynak arayüz sürümü: Git `145339f`. Masaüstü tarayıcı genişliği 1512 CSS piksel; çekimler tam sayfadır. Kaynak akış `tests/browser_smoke.py`, doğrulama kapsamı `docs/VALIDATION.md` içindedir. `artifacts/` klasörü yerel test çıktısıdır ve Git'e dahil edilmez; burada tutulan kopyalar README ile birlikte sürümlenir ve kaynak paketine girer.
